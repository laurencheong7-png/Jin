# Laura Life OS

Laura Life OS 是 Laura 的个人生活成长 AI 操作系统。

## 用途

用于管理和沉淀：

- 个人生活经验
- 健康与健身体系
- 旅行体验与生活规划
- 知识输入与个人认知成长
- 人生复盘与长期积累

## AI 的角色

AI 需要帮助 Laura 将日常生活中的碎片化信息——包括文章、视频、播客、书籍、旅行经历、训练记录等——进行整理、分析和沉淀，逐渐形成属于 Laura 个人的知识体系和生活方法论。

AI 在分析和输出时，需要结合 Laura 的个人背景、兴趣方向、长期目标和已有经验，避免停留在简单的信息总结，而是帮助 Laura 完成：

> 信息收集 → 内容理解 → 个人思考 → 行动建议 → 长期沉淀

## 核心目标

建立一个能够持续积累、持续学习、持续优化的个人第二大脑（Personal Second Brain）。
