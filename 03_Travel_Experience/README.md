# Laura Travel Planner

这里保存 Laura 的旅行攻略与长期旅行经验。默认采用“地图优先型”四阶段流程。

## 新旅行如何开始

1. 复制 `_template` 文件夹，并重命名为 `YYYY-MM_目的地`。
2. 填写 `trip-brief.md`，至少确认目的地、出发地、日期或天数、同行者和跨城交通方式。
3. 按四个确认节点推进：城际路线 → 景点筛选 → 分日规划 → 每日细化。
4. 在 `sources.csv` 记录所有易变化事实、图片和地图数据的来源。
5. 完成后按照 `qa-checklist.md` 检查手机、打印、路线合理性和信息日期。

## 标准目录

```text
YYYY-MM_目的地/
├─ index.html          # 地图优先型攻略主页
├─ trip-brief.md       # 启动信息与确认状态
├─ sources.csv         # 信息、图片与地图来源
├─ qa-checklist.md     # 发布前检查
├─ maps/               # 城际、总览与每日路线图
└─ images/             # 景点图片
```

## 默认规划规则

- 候选景点：10–15 个，分为必去经典、在地体验、机动备选。
- 行程节奏：每天 2–4 个核心点，保留用餐、休息和临时调整时间。
- 路线排序：综合真实距离、开放时段、停留时间、交通和体力，不只按直线距离。
- 餐饮：只建议适合用餐的区域，除非旅行任务另行要求具体餐厅。
- 住宿：不参与首轮聚类；酒店确定后执行一次路线校正。
- 变动信息：优先引用官网或官方旅游来源，并标注查询日期；不确定内容标为“出发前复核”。

## Skill 策略

第一趟旅行先使用现有搜索、浏览器核验、地图可视化和 HTML 能力验证流程。旅行结束后，再根据实际完成率、信息准确率和使用体验决定是否制作 Laura 专属旅行规划 skill。
