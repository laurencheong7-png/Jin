# 旅行攻略验收清单

## 信息可靠性

- [ ] 开放时间、预约、闭馆日等易变化信息来自官网或当地官方旅游来源。
- [ ] 每条易变化信息都标注查询日期。
- [ ] 未确认信息明确标记“出发前复核”。
- [ ] 图片、地图数据和事实来源已写入 `sources.csv`。

## 路线合理性

- [ ] 地图使用真实坐标与公开地理数据，没有手画地理轮廓。
- [ ] 每天安排 2–4 个核心点，并留有用餐、休息和机动时间。
- [ ] 已检查开放时段、预计停留、交通衔接和体力强度。
- [ ] 过满行程标有删减优先级。
- [ ] 天气敏感或可能闭馆的项目有替代项。
- [ ] 酒店确定后已重新检查每日起终点与交通。

## 页面与打印

- [ ] 电脑宽度下地图、文字和图片没有重叠或裁切。
- [ ] 手机宽度下导航、路线摘要和景点图片可正常阅读。
- [ ] 图片使用明确尺寸且不变形。
- [ ] 打印或导出 PDF 后，地图、标题和每日路线没有被错误分页。
- [ ] 所有本地图片和地图路径可用，断网后核心攻略仍可阅读。

## 出发前复核

- [ ] 交通线路与预计耗时仍合理。
- [ ] 预约项目已经完成或有明确提醒。
- [ ] 临时闭馆、维护和天气风险已复查。
